## 一、为什么不用 fish_heart，而是自己写

调查 fish_heart（`Vivy33/astrbot_plugin_fish_heart`）后的结论：**它是好插件，但不能直接用**。

| 问题 | 说明 |
|---|---|
| 和你现有三套重叠 | 它自带走主动说话、作息、念头，会和 `proactive_chat` 打架 |
| 全局单例 | 它自己承认「九维是全局单例，建议只服务一个主要对象」，但你群聊私聊都有 |
| 有成人的欲 | 默认关，但你的人设写着「不是谁的恋人」，整块不想要 |
| 维度不完全合适 | 它 9 维里有「反刍」「社交」，前者基本触发不到，后者和依恋语义重叠 |

**但它的三个技术点值得直接学**：
1. **注入走 `extra_user_content_parts`**，不碰 system prompt —— 实测能省每月 6.5 元缓存损失
2. **纯标准库零依赖** —— 不引入额外安装负担
3. **关键词感知 + 热度折扣** —— 零额外 token 成本判情绪

所以：**照着它的骨架重写一个，装你自己的维度、你已有的阶段名、你需要的边界。**

## 三、职责边界（最重要的一节）

现行系统里有四个"心情/关系"相关的东西，新插件只接其中两个：

```
┌─ 房间状态机 home-state.js（Node，唯一管辖）────────────┐
│  needs: hunger / thirst / fatigue / pain              │
│         hygiene / bladder                             │
│  → 驱动她在 3D 房间里的行为（31 处耦合）               │
│  ✅ 新插件只读，绝不写                                  │
└───────────────────────────────────────────────────────┘

┌─ 大肥鱼的心 soul（新建，唯一管辖）─────────────────────┐
│  情绪 7 维 + 责怪压力 + 五档 + 念头 + 里程碑            │
│  → 决定她"说话什么语气"                                │
│  写 soul.json，房间页读它展示                          │
└───────────────────────────────────────────────────────┘

┌─ affinity.js（废弃）──────────────────────────────────┐
│  好感度 6 阶段 —— 实测从未运行（affinity.json 不存在）   │
│  ✅ 阶段名搬进新插件，逻辑重写，文件保留不删            │
└───────────────────────────────────────────────────────┘

┌─ group_chat_plus 的 mood（关闭）──────────────────────┐
│  关键词判情绪 → 塞进 system prompt                     │
│  ✅ 关闭（同时消除缓存污染，每月省 6.5 元）             │
└───────────────────────────────────────────────────────┘
```

**关键原则**：身体归房间，心情归 soul，两者只读不写对方。

## 四、7 维定义

| 维度 | 键名 | 基线 | 半衰期 | 含义 | 谁推它 |
|---|---|---|---|---|---|
| 依恋 | `attachment` | 45 | **51 h** | 想不想你 | 夸奖、哄、撒娇；**闲聊不加** |
| 亲密 | `intimacy` | 40 | **51 h** | 亲近感 | 夸奖、撒娇；闲聊每句 +0.1 |
| 开心 | `joy` | 50 | 10 h | 开心程度 | 几乎所有正向互动 |
| 担心 | `worry` | 15 | 10 h | 放心不下 | 你说累、熬夜、受委屈；事情没结果 |
| 难过 | `sad` | 10 | 10 h | 被否定、被冷落 | 被凶、被敷衍、被比较 |
| 好奇 | `curious` | 55 | 8 h | 想不想知道 | 日常对话、你发图/链接/新东西 |
| 疲惫 | `fatigue` | 20 | 9 h | 累不累 | 连续聊天累积；安静时回落 |

**依恋和亲密是"存量"**（半衰期 51 小时），表示关系不会因为一次冷淡就归零，但会缓慢疏远。
其余是"情绪"（半衰期 8~10 小时），会自然地来去。

**天花板**：所有增益按 `(1 - 当前/100)` 缩放，100 是渐近线不是硬切。

## 五、五档状态

| 档位 | 责怪压力 | 表现（只影响语气） |
|---|---|---|
| 日常 `calm` | < 25 | 正常说话 |
| 委屈 `wronged` | 25–55 | 话变短，会问"是不是嫌我烦" |
| 生气 `angry` | 55–70 | 冷、短、带刺，把话挑明 |
| 害怕 `afraid` | 70–80 | 不顶嘴，先确认你还想不想聊 |
| 回避 `shut` | ≥ 80 | 少说、不讨好、不追问 |

**和你现有系统的区别**：fish_heart 的回避档"前 5 条不回话"，**我们不做**。
所有档位都正常回话，只是语气不同。—— 避免和 `proactive_chat` 的调度冲突。

**哄够了就行**：不要求必须"道歉"，连续哄够轮数就往下走（日常/委屈/生气 1 轮，害怕/回避 2 轮）。

**心结 40**：没人哄时责怪每 6 小时褪 8 点，**止于 40**，不会自己回日常。

## 七、技术架构

```
astrbot_plugin_dafeiyu_soul/
├── metadata.yaml          插件元数据（astrbot_version >= 4.24.2）
├── _conf_schema.json      配置架构（面板可调）
├── core.py                ★ 纯函数层：衰减/事件/档位/注入文本
│                            零依赖、零 IO，可单独单测
├── perceive.py            ★ 关键词感知：中文正则 → 事件
├── main.py                AstrBot 接入层：钩子、命令、心跳
├── test_core.py           单元测试（python -m unittest）
└── views/soul/index.html  P2 面板（4.29 用 views/）
```

### 注入方式（关键技术点）

```python
# ❌ 不这么做（group_chat_plus 现在这样，会污染前缀缓存）
req.system_prompt += mood_hint

# ✅ 这么做（AstrBot 官方 datetime 也这样）
req.extra_user_content_parts.append(TextPart(text=block))
```

**为什么**：DeepSeek 前缀缓存从开头算到第一个变化点。system prompt 一变，后面整段历史全部重算。
实测你现在的低命中调用未命中中位数是正常组的 **5 倍**（16,838 vs 3,398 tokens）。

### 注入节流

- 跨档必注（日常→委屈→生气→害怕→回避）
- 同档内数值漂移按 `min_gap_minutes`（默认 20 分钟）节流
- 生气档例外：每轮都注（否则下一轮她"忘了自己在生气"）

### 落盘

```json
{
  "version": 1,
  "updatedAt": 1795...,
  "dims": { "attachment": 45, "intimacy": 40, "joy": 50, ... },
  "blame": 0,
  "events": [ { "at": ..., "kind": "praise", "dim": "attachment", "delta": 2.5 } ],
  "milestones": [],
  "promises": []
}
```

**不存聊天原文**，事件只记 `kind` + 数值变化 + 20 字以内的摘要。

### 踩到的三个坑（都已修）

1. **相对导入** —— AstrBot 把插件当包加载（`data.plugins.<pkg>.<mod>`），
   `import core` 报 No module named 'core'。必须 `from . import core`。
2. **soul.json 不生成** —— 原来只在状态变化时写，启动时不写，
   房间页会一直读不到。改成 `__init__` 里启动就写一次。
3. **面板 401** —— 裸 `fetch` 拿不到 asset_token。必须走
   `bridge.apiGet / bridge.apiPost`（AstrBot WebUI 注入的 SDK）。

### 回滚方法

```bash
# 关新插件
sed -i 's/"enabled": true/"enabled": false/' /root/data/config/astrbot_plugin_dafeiyu_soul_config.json

# 恢复旧情绪系统
cp /root/data/config/astrbot_plugin_group_chat_plus_config.json.bak-soulmigrate-* \
   /root/data/config/astrbot_plugin_group_chat_plus_config.json

systemctl restart astrbot
```
