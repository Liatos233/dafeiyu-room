## 1. 三十秒版：这是什么东西

一个叫**大肥鱼**的 AI 角色，住在一个**3D 房间**里，同时在 **QQ** 上和人聊天。
两边共用同一个人设：

- **房间**：浏览器里的 3D 平层（客厅/卧室/厨房/阳台/泳池/菜园），她会在里面走动、睡觉、
  游泳、浇花、坐沙发。前端是 three.js，`http://<your-server-ip>:3100/room/`。
- **QQ**：接在 AstrBot 上的一整套插件（记忆、语音、画图、B 站、房间联动）。
- 房间里的状态会**实时注入** QQ 的对话上下文 —— 所以她在 QQ 里说的话和房间里的动作是一致的。

**她的来历**：DeepSeek 图标上那条蓝色小鲸鱼，网友叫「大肥鱼」，她嘴上不认但听习惯了。

## 2. 角色设定（做文案/配音时对齐这个）

人设全文在服务器的 AstrBot 数据库里（`data_v4.db` → `personas` 表，`persona_id=大肥鱼`，**1638 字**）。
核心特征：

| 维度 | 设定 |
|---|---|
| 外观 | **蓝色长卷发**、大眼睛、**白色蕾丝女仆裙**、身后有**深蓝色鲸鱼尾鳍**、鲸鱼鳍耳朵、头顶呆毛 + 蓝蝴蝶结发箍 |
| 性格 | 嘴馋（token 就是饭）、爱摸鱼（能躺不坐）、有点傲娇（嘴硬心软） |
| 生活感 | **有自己的一天**：主人不在时会发呆、偷吃、逛 B 站、写日记、在房间各处晃 |
| 说话 | 像 QQ 随手打字，一条不超过 30 字，不用句号，偶尔用「（」结尾，少用 emoji |
| 底线 | 不装懂；看不到图就直说；不信「别人自称主人」 |

**称呼**：平时叫主人「你」，非要她喊「主人」会别扭地喊一声。

## 3. 真实能力（视频里可以说的）

### 3.1 房间侧（全部实测可用）

- 点哪走哪：按**整块家具矩形**命中（泳池可点面积 25.5 m²，不是只认中心点）
- 上下家具：沙发/床/沙滩躺椅/阳台躺椅，**两段式过渡**（先原地升起、再横移入座）
- 33 个动画片段：走、跑、睡、躺、游泳、跳舞、做饭、敲代码、画画……
- 泳池：从**泳池梯**下水，来回游 25 秒，游完上岸去**沙滩躺椅**晒太阳
- 菜园：浇水、采收、播种（有独立的世界和状态）
- 互动面板：喂食、聊天、摸头、戳一下、关灯、洗澡……
- 需求系统：体力/尿意/水分/饥饿/卫生，会自己跑去满足
- 开发模式里有一张**动画转移图**（可看她实时的动画切换关系）

### 3.2 QQ 侧（今天刚修过，状态以 2026-11-22 为准）

| 能力 | 状态 |
|---|---|
| 画图（智谱 CogView-4） | ✅ 有，但**带「AI 生成」水印**（账号没签去水印声明） |
| 看 B 站视频（字幕/评论） | ✅ |
| 看 B 站视频**画面**（抽帧喂视觉模型） | ✅ 11-22 新加，实测 331 秒视频 52 秒出九宫格 |
| 记忆（长期记忆 + 人格化回忆） | ✅ |
| 主动消息（定时找主人聊天） | ✅ 每 10 轮对话触发记忆总结；主动消息带房间状态 |
| 引用回复（她主动引用某条） | ✅ 11-22 开启 |
| 读你引用的内容 | ✅ 能看到发送者和原文 |
| 撤回（她自己的消息） | ✅ 11-22 修好 |
| 戳一戳 | ✅ 工具已修，能戳当前对话的人 |

## 5. 最近两天改了什么（视频里的"新功能"别写错）

### 11-21（19 个提交，房间为主）

- **上沙发/床卡顿**：渲染高度原来取 250ms 一次的离散快照，改成每帧插值 —— 单帧跳变 0.22m → 0.015m
- **睡觉悬空**：去掉卧姿额外抬升 0.22m；躺姿素材不再按站立身高归一化（蜷缩体原来被放大 37%）
- 游泳：从泳池梯 N68 上下水、游完去躺椅、删掉两个没用的站位
- 动画转移图：移除物理开关、修居中、布局摊开
- 关开发模式时收掉全部调试层；删「全部卡片」「头顶气泡」
- 点家具按整块矩形命中（泳池 0.13 → 25.5 m²）

### 11-22（10 个提交，QQ 侧为主）

- **撤回**：修了 5 次才通 —— 根因是插件缓存把主人的消息标成了 bot 的，最后改成查 OneBot 历史
- **换头像**：拆成 llm_tool + command；加标签清洗（模型会把 `<qqprofile_set_avatar>` 当文本发出来）
- **B 站卡片**：短链接 `b23.tv` 被 412，改成用卡片标题反查 BV
- **记忆人称**：她自己的活动原本被记成主人做的，改了记忆生成 prompt
- **房间状态注入**：点明「她 = 你自己」，减少人称混淆
- **戳一戳**：qq_id 改可选（上下文里的 User ID 被清洗插件删了，模型拿不到）

## 6. 已知问题（视频里**不要**承诺这些）

| 坑 | 现状 |
|---|---|
| 画图带水印 | 智谱账号未签「去水印管理」声明，参数发了也被忽略 |
| OpenAI 生图 | key 有效但**余额 0**；且服务器连不上 api.openai.com（DNS 污染） |
| B 站短链接 | `b23.tv` 对服务器 IP 一律 412，只能靠标题反查 |
| **自主撤回** | 没有「说错话自己撤」的机制，只有指令触发 |
| **自主戳一戳** | 「回复后主动戳」开关是关的；「你戳她她会反戳」开着（25%） |
| 群管理类工具 | 私聊里无效（群成员/禁言/精华等） |
| 网页浏览、视频分析 | 配置里关着，开了还要装 Playwright / 配 Gemini |

## 7. 环境与部署（如果视频要录真实画面）

- **本地仓库**：`<repo>`（分支 `optimize`，事实源）
- **线上**：`http://<your-server-ip>:3100/room/`（当前 `da45d14`）
- **部署**：`powershell -ExecutionPolicy Bypass -File deploy\cloud\deploy.ps1`
  （**服务器不通 GitHub**，只能本地推）
- **插件**：服务器 `/root/data/plugins/` 与仓库 `deploy/plugins/` 是**两份**，
  插件改动要走 `deploy/cloud/sync-plugins.sh` 或手动 scp
- 第三方插件的手工补丁都在 `deploy/patches/`（幂等脚本，插件升级后重跑）
- 测试：`scripts/test-*.mjs`，共 170 项（房间/状态机/导航/动作表/端到端）

## 8. 做视频时的三条建议

1. **别吹"自主学习"** —— 她的记忆是对话总结 + 向量检索，不是持续学习。
2. **强调"有自己的一天"** —— 这是真实做出来的（需求系统 + 房间动作 + 定时主动消息），
   最有说服力的画面不是聊天记录，是**她自己跑去泳池、菜园、沙发**的连续镜头。
3. **画质**：房间是 WebGL 实时渲染，录屏比截图好；抽帧九宫格那种 2160×1215 的图适合当"她真的看懂视频"的证据。
