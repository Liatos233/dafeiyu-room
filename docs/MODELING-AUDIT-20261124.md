# 房间建模审查报告（2026-11-24）

> 审查方式：读代码（`world.js` 2998 行 / 2834 行逻辑 + `actor3d.js` + `model-actor.js`）
> + 实际渲染四组视角截图（`debug=top` / `debug=flat` / `debug=room:<id>` / `view=eyes`）。
> 截图在 `shots/`：`views-top.png`、`views-flat.png`、`views-eyes.png`、`room-*.png`。

---

## 先说结论：不是「建模粗糙」，是三类具体问题

| 类别 | 数量 | 影响 | 修复成本 |
|---|---|---|---|
| **A. 光照/阴影缺失** | 3 项 | 最大 —— 直接决定「真实感」 | 低（改参数） |
| **B. 几何精度不足** | 4 项 | 中 —— 近景有棱角、边缘硬 | 中（改分段数） |
| **C. 细节/一致性缺失** | 6 项 | 中 —— 「不和谐」的来源 | 中 |

材质体系其实做得**很好**（35 个语义化材质槽、roughness/metalness 有明确区分、
玻璃用 MeshPhysicalMaterial、镜子带 envMapIntensity 1.4），这块不用动。

---

## A. 光照与阴影（优先级最高）

### A1. 76 个 Mesh，只有 8 处 `castShadow = true`

**这是「发飘、不真实」的头号原因。**

```
castShadow=true: 8
receiveShadow=true: 10
Mesh 总数: 76
```

也就是说**大约 90% 的家具没有投射阴影**。俯视图里能看到沙发、茶几、书架、
马桶、洗手台这些东西下面几乎是干净的——它们「浮」在地板上。

地面 `receiveShadow = true` 了，但源头不投，接也白接。

**建议**：给所有「离地有高度的实体」加 `castShadow`。落地家具（地毯、地板贴图）
不需要。可以写个遍历：`world.root.traverse(o => { if (o.isMesh && o.position.y > 0.05) o.castShadow = true })`，
或者按家具构件逐个补。

**代价**：阴影贴图 2048²，多 60 个投射体大约增加 15~25% 渲染开销。可接受。

---

### A2. 室内灯「全部为 0 强度」，只有渲染点光时才亮

```js
const light = new THREE.PointLight(0xffd6a6, 0, 7.5, 2);   // ← intensity: 0
light.userData.baseIntensity = intensity;                  // 真正的值存这儿
```

9 盏房间主灯 + 4 盏局部灯（落地灯/床头灯/台灯/吊灯），**初始强度全是 0**，
只在「灯开着」时才被赋值。问题：白天/夜晚切换、灯关着的时候，室内**完全靠
`HemisphereLight(0.5)` + `DirectionalLight(2.0)` 撑**，而这两盏都是「室外光」，
不区分房间，导致：

- 房间之间没有明暗层次（截图里厨房和客厅亮度几乎一样）
- 深处角落（走廊、卫生间）和靠窗位置一样亮

**建议**：给灯关状态也保留一个低强度（比如 `0.15`），或者加**房间级环境光**
（每个房间一盏 `RectAreaLight` 或低强度 `PointLight`，不受灯开关控制）。

---

### A3. 阴影相机范围偏大，精度浪费

```js
sun.shadow.camera.left = -14, right = 14, top = 15, bottom = -15;   // 28×30 米
sun.shadow.mapSize = 2048;
```

房间是 13.2 × 9.0 米，阴影相机覆盖 28×30 米 → **每米只有 73 像素**。
阴影边缘会有明显锯齿，尤其是小物体（杯子、植物叶片）。

**建议**：收到 `-8..8 / -7..7`（覆盖房子 + 泳池），每米能到 128 像素。
或者把 `mapSize` 提到 4096（代价：显存 4 倍）。

## B. 几何精度

### B1. 球体分段数偏低（15 个球，平均 10 段）

`SphereGeometry(0.26, 18, 12)` 这种还好，但大量小物件是 `(0.045, 8, 6)`、
`(0.028, 10, 8)` —— 8 段的球在近景是**八边形**。

俯视图能看出：植物叶片、水果、灯泡都是明显的多边形。

**建议**：分档
- 大件（>0.2m）：24×16
- 中件（0.05~0.2m）：16×12
- 小件（<0.05m）：12×8（原 8×6）

小件数量不多，总顶点增量很小。

---

### B2. 圆锥只有 3 段（7 个）

`ConeGeometry` 平均 3 段 = 三棱锥。用来做植物、尖顶装饰时会很扎眼。

**建议**：至少 8~12 段。

---

### B3. 圆柱 11 个，最小 6 段

水管、桌腿、灯柱这类细长圆柱，6 段在近景能看出棱。

**建议**：细长件 12 段起。

---

### B4. 没有 LOD，也没有几何合并

```
LOD: 0
mergeGeometries: 0
InstancedMesh: 2
```

条件允许时可以：
- 远处家具用低模（LOD）
- 同类重复件（书架上的书、地砖、栏杆柱）用 `InstancedMesh`

不过**这不是当务之急** —— 现在 76 个 Mesh 对现代 GPU 毫无压力。
列在这里是因为「以后加更多家具」时会变成瓶颈。

---

## C. 细节与一致性（「不和谐」的主要来源）

### C1. 墙面几乎全白，没有踢脚线/顶角线

截图里所有墙都是同一个 `M.wall (0xe9e2d6)` 大平面，**从地到顶一个颜色**。
真实房间里：
- 踢脚线 8~12cm（深色或白色）
- 顶角线 5~8cm
- 墙面和天花板交界有阴影缝

`M.base` 材质**已经定义好了**（`0xd6cbbb`），但只在很几处用到。
`buildShell` 里没看到系统性的踢脚线。

**建议**：给每个房间四周加一圈踢脚线（一个 BoxGeometry 环，或者 4 条盒子）。
成本极低，视觉提升明显。

---

### C2. 门窗洞口有「黑边」，缺少门框/窗框收口

`views-eyes.png` 里能看到：**门洞边缘是纯几何切面，没有门框**，
看起来像「墙上挖了个洞」。窗洞有窗框但比较简单。

**建议**：门洞加一圈 5~8cm 的门套（4 条盒子），窗洞加窗台板。

---

### C3. 天花板几乎没有细节

`views-flat.png` 看天花板：除了 8 个筒灯圆片，**完全平的**。
真实房间至少有：
- 灯槽/石膏线
- 窗帘盒
- 空调出风口
- 吸顶灯（现在吊灯只有餐厅一个）

**建议**：加一圈石膏线 + 客厅/卧室各一个吸顶灯。

---

### C4. 家具「贴地生长」，缺少接地感

配合 A1（没阴影），加上家具都是直接放在 `y=0`，
**没有任何过渡**（没有地毯收边、没有家具脚垫、没有阴影渐变）。

**建议**：可以给主要家具（沙发、床、桌）在底部加一圈**接触阴影**
（一个半透明黑色平面，或者贴图），即使不实时投影也能有「压在地上」的感觉。
这是低配替代方案，比 A1 便宜。

---

### C5. 窗外景观单一

`skyTexture(hour, weather)` 生成的是**渐变天空**，
`views-flat.png` 里窗外就是一片蓝色渐变，**没有远景**。

房间叫「海景房」（有沙滩、泳池），但窗外看不到海、沙滩、远山。

**建议**：在窗外放一个**billboard 远景**（一张手绘的海平线贴图），
或者加几层半透明的远山/云。成本低，氛围提升大。

---

### C6. 泳池露台过于空旷

`views-flat.png` 看泳池区：**一把伞 + 两张躺椅 + 一个大泳池**，
周围大片空白。

对比室内（有书架、植物、画、地毯、各种小物件），露台显得很「空」。

**建议**：加
- 池边台阶/淋浴柱
- 几盆植物
- 小边桌
- 沙滩毛巾/浮圈

## 附：审查中确认「做得不错」的部分（不用改）

| 项 | 说明 |
|---|---|
| 材质系统 | 35 个语义槽，roughness 从 0.06（玻璃）到 1.0（土），分层合理 |
| 墙体系统 | 带门洞/窗洞参数化，转角的「顶面低 4mm」避免共面打架 |
| 地面过渡 | 木地板 + 各房间地砖（略高 8mm，避免 z-fighting） |
| 家具比例 | 单人床 1.2m、沙发座 0.48m、走道 ≥0.9m —— 都是真实尺度 |
| 纹理生成 | 木地板 1024²，程序化生成，带木纹/接缝 |
| 玻璃 | MeshPhysicalMaterial + depthWrite:false，处理了透明排序 |

## 我想先确认的事

1. **性能预算**：现在线上是手机看还是电脑看？如果是手机，A1 的 60 个投射体要
   分批加（或者用 C4 的接触阴影替代）。
2. **风格定位**：现在是**低多边形扁平插画风**（看截图很明显）。如果把分段数
   拉太高、加太多写实细节，反而会和「扁平」的家具造型不搭。
   —— 我倾向**保持扁平风**，只补「阴影 + 踢脚线 + 门套」这类结构性的东西，
   不追求写实。
3. **优先级**：如果只做 3 项，我建议 **A1（阴影）+ C1（踢脚线）+ A3（阴影精度）**，
   这一组能让画面立刻「落地」。
